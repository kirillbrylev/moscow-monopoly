# Монополия — Москва

Браузерная «Монополия» с московскими улицами (от Житной до Арбата). Четыре файла, без сборки.

## Играть

После публикации на GitHub Pages откройте ссылку вида:

https://kirillbrylev.github.io/moscow-monopoly/

Или локально:

```bash
python3 -m http.server 8765
```

Затем http://localhost:8765  
Не открывайте `index.html` как файл: модули ES так не загрузятся.

## Что умеет

- Поле 40 клеток, фишки, 3D-кубики
- Покупка, аукцион со своей ставкой, аренда, дома и отели
- Залог, тюрьма, «Шанс» и «Казна», банкротство
- Кирилл и Артём за одним экраном, боты Март, Лох, Мирон и Ашот
- Чат, торговля улицами и деньгами
- Сохранение в браузере (`localStorage`)

Партия живёт в том браузере, где вы играете. Это не сетевая комната на двоих с разных компьютеров.
